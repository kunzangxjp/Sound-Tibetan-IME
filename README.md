# Sound-Tibetan-IME
This allows users to type Tibetan words based on the English pronunciations of Tibetan words. One can customise the word list according to one's own pronunciation preference.

After typing the pronunciation in the Input field, possible Tibetan words will appear. Type the corresponding number next to the desired word and the system will append it to the Result field. One can then copy and paste the resulting phrase or sentence to the other applications.

The intended audience to this system is user who is already able to pronounce Tibetan words and is able to type the English pronunciations. The words list is still expanding. Do visit this website frequently for the updates on the words list.
